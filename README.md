# Hostel Care – Backend (Java + Spring Boot + MySQL)
Run locally: install JDK 17 + Maven + MySQL, then `mvn spring-boot:run` (API on http://localhost:8080).
Default admin: admin@hostel.com / admin123 (override with ADMIN_EMAIL / ADMIN_PASSWORD).
Env vars: DB_URL, DB_USERNAME, DB_PASSWORD, JWT_SECRET (32+ chars), FRONTEND_URL.
Deploy: Render Web Service, Runtime = Docker.
